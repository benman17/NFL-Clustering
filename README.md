# NFL Fantasy Player Clustering 🏈

This project applies **K-Means clustering** to group NFL players into fantasy football tiers using historical performance data.  
It was developed in **Google Colab** using **PySpark**, with visualization done in Matplotlib/Tableau.

## Project Highlights
- Data collection and preprocessing in PySpark
- K-Means clustering model for tiering players
- Data visualizations of player clusters
- Discussion of insights for fantasy draft strategy

## Tech Stack
- Python, PySpark
- Pandas, Matplotlib
- Jupyter/Google Colab
